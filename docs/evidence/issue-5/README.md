仓库实际入口为 `python3 scripts/check.py`，先执行本仓 Corp 检查，再执行根 unittest。新增测试使用真实临时 Git，覆盖工作区及未跟踪变化、PR base 与合并 checkout 区别、push／初次 push／manual、缺失或不可达基线、浅历史、断链、必需阶段路由、helper 语法、卡路径与无关技能边界。无外部网络；没有用假的空差量替代缺失基线。

[旧项目采纳](old-project-adoption.json)通过旧版及候选的真实 CLI 证明不同包重装拒绝覆盖，随后显式适配并运行本地检查，保留自有卡、审查承诺、固定 Spec／checkpoint 文本和初始安装溯源。最初一次探针因未解析路径别名而先触发外层仓库保护，已单独保留于 [被排除的初次记录](old-project-adoption-initial.json)，不计入升级拒绝证据。这里的 Spec／checkpoint 是本地夹具记录，不代表服务端接受或真实项目采用。

分发方法与本仓自身对应方法、checker 已分别适配并核对相等；项目自有入口、Canon、沟通卡、准备事实及原安装溯源保持其 owner。独立复制安装和移除创建包后的 checker 运行由实际测试覆盖。适用旧证据保留在 [Issue 3](../issue-3/README.md)，包括显式审查承诺、已有占用、晚到者和未形成整体候选等未变协议；不重复计为本轮新观察。
